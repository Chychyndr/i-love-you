# <img src="./favicon.svg" alt="" width="32" height="32"> i love you

A tiny static HTML page with an animated heart made from `i love you` text.

## Files

- `index.html` — the website and heart animation
- `favicon.svg` — the monochrome project icon
- `.nojekyll` — tells GitHub Pages to publish the site as plain static files
- `CNAME.example` — example for a custom domain. Rename it to `CNAME` and put your real domain inside

## Local preview with uv

```bash
uv run python -m http.server 8000
```

Open:

```text
http://localhost:8000
```
